# Standard Clarifications Reference

Boilerplate clarifications that go in the Notes and Clarifications section at the bottom of every SOW.

## Always Included

These appear in every SOW unless the user explicitly removes them:

- All work assumes normal site access during standard working hours
- Existing conditions per site visit; SOW based on drawing review only
- Pricing and scope based on drawings dated [DRAWING DATE] only
- Coordination with other trades required as applicable
- Subcontractor responsible for cleanup of own work into centralized container provided by GC
- Subcontractor responsible for protection of own work and adjacent finishes
- All testing required per drawing specifications, local code requirements, and industry standards is included
- All required permits and inspections per local code are included unless explicitly noted as excluded

## Drawing-Specific Clarifications

These are pulled from the drawing.md files during extraction. Examples of triggers:

| Trigger in Drawings | Clarification to Add |
|---------------------|----------------------|
| "TBD" callout on a spec | Spec for [item] shown as TBD on [sheet] — RFI required prior to ordering |
| "VIF" (Verify in Field) | Dimensions for [item] noted VIF on [sheet] — confirm in field |
| Conflicting specs between sheets | See Conflicts section — RFI required to resolve |
| "Match Existing" callout | Existing condition match per site visit — assumes typical condition |
| "By Others" notation | [Item] noted "By Others" on [sheet] — not included in this scope |
| Detail referenced but not shown | Detail [X] referenced on [sheet] but not provided — RFI required |

## Trade-Specific Clarifications

When generated, place these inside the relevant trade scope section, NOT in the bottom Notes section.

**Demolition:**
- All hazardous materials handling excluded — separate scope and pricing
- Cutting, capping, and patching of MEP systems by respective MEP subs

**Concrete:**
- Concrete mix design per structural drawings and engineer specifications
- Cold weather protection per ACI 306 if work occurs below 40°F

**Drywall:**
- Level of finish per architectural specifications; default Level 4 if not specified
- Includes installation of doors, frames, hardware, and bathroom accessories furnished by others

**HVAC:**
- Equipment selection based on schedule shown; substitutions require GC approval
- Test and balance by HVAC sub unless noted otherwise

**Electrical:**
- Existing electrical disconnects and safe-offs prior to demolition included
- Temporary power and lighting included per project requirements

**Plumbing:**
- Rough-ins for owner-supplied or F/O fixtures included
- Cutting and patching of finishes incidental to plumbing work by others
