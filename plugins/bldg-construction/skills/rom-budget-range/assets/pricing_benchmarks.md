# Pricing Benchmarks

Comparable NYC projects to anchor a new estimate. Update as new projects close.

## Restaurant — West Village / SoHo

### Paolo (168 Bleeker St, 2026)
- 2,000 SF, mid-tier, NEW restaurant
- Includes: full new kitchen equipment, FF&E (tables/chairs), full new HVAC heat pumps
- Schedule: 26 weeks (6 months)
- Total: **$1,399,287** = $700/SF gross
- Direct cost: $1,209,196 = $605/SF (86.4% of total)
- Markup ratio: 13.6% (GC 6.1% + Fee 4.6% + Insurance 2.9%) — note Paolo used no explicit design contingency line; that 13.6% is roughly equivalent to BLDG standard 15% (GC 7 + Fee 5 + Insurance 3) without contingency
- Divisional shares: Div 01 GR 13.7% / Div 09 Finishes 14.2% / Div 11 Kitchen Equip 8.4% / Div 22 Plumbing 7.3% / Div 23 HVAC 12.3% / Div 26 Electric 11.7%

### MacDougal Street Restaurant / Mosconi (69-71 MacDougal, 2026)
- 2,138 SF FOH (4,000 SF main + 2,960 SF cellar = 6,960 SF gross), mid-to-high-end RENOVATION
- Kitchen stays in place, bar relocates, full FOH gut, new bathrooms (allowance), HVAC reuse base
- Schedule: 6 months
- **Tier A (mid-tier upscale, HVAC reuse): $1,916,430** = $896/SF FOH
- **Tier A + HVAC replacement: $2,240,280** = $1,048/SF FOH
- **Tier B (high-end signature, HVAC reuse): $2,485,390** = $1,162/SF FOH
- **Tier B + HVAC replacement: $2,851,150** = $1,334/SF FOH
- Markups: GC 7% / Fee 5% / Insurance 3% / Contingency 12% (total 27%)
- Bath allowance: $85K/bath × 2 = $170K both tiers

## $/SF translation rules

When using a benchmark from a different scope:

**To compare to MacDougal-style renovation (kitchen stays, no FF&E, FOH gut)**, take Paolo's $700/SF and:
- Subtract kitchen equipment: −$58/SF → $642/SF
- Subtract FF&E (tables/chairs that were inside Paolo's kitchen line): −$20/SF → $622/SF
- Subtract part of HVAC if reusing equipment: −$30/SF → $592/SF
- Add demolition delta (renovation has more demo than fit-out): +$30/SF → $622/SF
- Add bathroom allowance (Paolo had minimal bath work): +$50–80/SF → $672–702/SF
- Add design contingency 12% layer: +$84/SF → $756–786/SF

That's the "Paolo equivalent renovation" baseline. Anchored against this, MacDougal Tier A at $896/SF is +$110–140/SF higher — defensible because (a) smaller footprint dilutes fixed costs less efficiently and (b) more comprehensive scope than Paolo's strip.

## Adjustments by neighborhood (anecdotal, refine over time)

| Neighborhood | Multiplier vs West Village baseline |
|---|---|
| West Village / SoHo / NoHo | 1.00× (baseline) |
| Tribeca | 1.05× (similar but slightly higher labor) |
| Midtown East / FiDi | 0.95× (more competitive open-shop pool) |
| Williamsburg / DUMBO | 0.90× |
| LIC / Astoria | 0.85× |
| Outer borough commercial | 0.80× |
| Hamptons / Westchester | 1.15× (logistics + labor markup) |

These are starting points. Verify against any recent project in the same neighborhood before adjusting.
