# Recording Evidence

Recorded on 2026-07-09 in Google Chrome using ProEst at `cloud.proest.com`.

Observed reusable sequence:

1. Navigate to ProEst and open Estimate Center.
2. Search for the target estimate/revision and open the matching estimate.
3. Open Reports.
4. Expand `Proposals`.
5. Select `2. Proposal + Exclusions [Insert SOV]`.
6. Use `Print` to save a PDF to `Downloads`.
7. Expand `GC Schedule of Values`.
8. Select `Estimate Cost Totals`.
9. Change grouping from `Divisions` to `Subdivisions`.
10. Use `Print` to save a PDF to `Downloads`.
11. Use Chrome's download control to show the new PDF in Finder.
12. Open the proposal PDF in Preview to verify proposal/Schedule of Values content.

- `2._Proposal_+_Exclusions_[Insert_SOV]_YYYY_MM_DD_<Estimate_or_Revision>.pdf`
- `Estimate_Cost_Totals_YYYY_MM_DD_<Estimate_or_Revision>.pdf`
