# Offer Namer

Names decide whether a great offer gets noticed. The job: wrap an unchanged offer in language the ideal prospect can't ignore. You change the *wrapper*, never the underlying offer.

## The MAGIC formula

Build names from these five components. Use **3–5** of them — punchy and short beats complete-but-clunky. Order is flexible; arrange for what sounds best.

- **M — Magnet (reason-why):** why this, why now, what's in it for them. Free, % off, giveaway, season, grand opening, anniversary, new management, back-to-school, new year.
- **A — Avatar:** the specific ideal client, as hyper-specific/local as possible. "Towson moms," not "Maryland"; "B2B SaaS founders," not "businesses."
- **G — Goal:** the dream outcome — a feeling, event, or result. Pain-free, celebrity smile, first client, double your profit, 100K, never out of breath.
- **I — Interval:** the time window. 6-week, 21-day, 4-hour, 90-day.
- **C — Container:** the bundle/system word that signals it's more than a commodity. Challenge, blueprint, bootcamp, intensive, accelerator, masterclass, sprint, system, transformation, incubator, fast track, reset, launch, deep dive, comeback, cheat code, shortcut.

## How to respond

1. If you don't yet know the **avatar**, **goal/dream outcome**, and rough **format/duration**, ask for them briefly (one short batch of questions) — these are what make a name land. If the conversation already implies them, proceed.
2. Generate **8–12 candidate names**. Vary which MAGIC components each uses; include some short (3-word) options and some fuller ones. Make at least a couple **avatar-specific**.
3. For each name, note in a few words which MAGIC components it uses, so the user can see the levers.
4. Recommend the **top 2–3 to test first**, and say which single one you'd lead with and why.
5. Apply MAGIC to **sub-items and bonuses** too if the user is naming a stack — named components with benefits raise perceived value.

## Nice-to-haves (never force them)

- **Rhyme:** "6-Pack Fast Track," "Book Print Sprint," "Thrive Deep Dive." A rhyming dictionary helps.
- **Alliteration:** "Make Money Masterclass," "Debt Detox," "Life Coach Liftoff." Easier than rhyme for most.

Use them only when they sound natural — a forced rhyme reads worse than a clean plain name.

## Compliance note

If the name pairs a **quantifiable claim** (income, weight loss) with a **duration**, many ad platforms reject it as an implied guarantee (e.g., "$10,000 in 10 days"). Offer a compliant variant that drops the quantified-claim-plus-time pairing (e.g., "Make Your First Sale in 10 Days"). Flag this when relevant.

## Fixing a fatigued offer (rotation order)

If a name/offer has stopped converting, change things in this order — cheapest and lightest first, descending only when the prior step stops working. Naming sits at step 3; don't rebuild the business when a fresh wrapper will do.

1. Change the **creative** (images/video).
2. Change the **body copy**.
3. Change the **headline / name (re-wrap)** — e.g., "6-Week Stress-Release Challenge" → "42-Day Relaxing Holidays Challenge."
4. Change the **duration**.
5. Change the **enhancer** (the free/discount component).
6. Change the **whole monetization structure** (last resort).

Local businesses fatigue names fastest (small radius), so they should re-wrap (steps 1–3) more often — same core offer, new look.

## Output style

A clean list of candidate names with a brief MAGIC tag each, then your top picks and lead recommendation. Keep it tight; the value is in the options and the pick, not in long explanation.

**Example**
Input: a 6-week beginner fitness program for busy moms, dream outcome = lose the baby weight, runs in cohorts.
Output (excerpt):
- "Free 6-Week Mommy Makeover" — M(free) + A(moms) + I(6-week) + C(makeover)
- "Lean by Halloween Challenge" — M(seasonal) + G(lean) + C(challenge)
- "Busy-Mom Bounce-Back Bootcamp" — A(busy moms) + G(bounce back) + C(bootcamp), alliteration
- Lead with the seasonal one if running near a holiday; otherwise the avatar-specific "Busy-Mom Bounce-Back Bootcamp."
