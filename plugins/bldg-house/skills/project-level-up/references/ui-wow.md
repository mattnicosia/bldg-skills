# UI wow protocol

Use this lane on primary surfaces only. The job is impact, not decoration.

## Pass bar

A surface fails if a sharp user would call it "nice" and keep scrolling. It passes when hierarchy and one signature moment are obvious in two seconds.

## Audit questions

1. What owns the screen in the first second?
2. Is the layout even and polite, or is there real scale contrast?
3. Do surfaces feel like material or like flat rectangles?
4. Is there a signature moment (entrance, interaction, or treatment) that is specific to this product?
5. Are hover, focus, active, loading, empty, and error actually designed?
6. Did motion change hierarchy, or did it only add movement?

## Round language (when proposing UI work)

Do not prescribe a palette unless a project profile exists. Push:

- extreme hierarchy on the one thing that matters
- at least one signature moment per primary surface
- material / depth / presence
- kill the safe middle

Landing / sign-in additionally:

- hero must dominate immediately
- sign-in is a premium moment, not a leftover form

## Anti-patterns

- more animation on an even layout
- generic cards, default type, soft gradient chrome
- rewriting the information architecture to chase a look
- restyling tokens the product already committed to
