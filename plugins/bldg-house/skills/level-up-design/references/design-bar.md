# Absolute Design Bar

Score each axis 0 to 3. 0 = broken, 1 = weak, 2 = solid, 3 = distinctive.
Target after rebuild: every axis 2+, at least three at 3.

| # | Axis | 0 (broken) | 3 (distinctive) |
|---|------|-----------|-----------------|
| 1 | Message clarity | Stranger cannot say what it is after 5s | Headline states outcome + who in one line, CTA verb is specific |
| 2 | Visual hierarchy | Everything same weight, no entry point | One dominant element per viewport, eye path is obvious |
| 3 | Typography | One size family, default font, cramped leading | Clear scale (ratio 1.25+), max 2 families, body 16-18px, line length 50-75ch |
| 4 | Spacing rhythm | Random gaps, cramped sections | Consistent 4/8pt scale, generous section breathing room |
| 5 | Color & contrast | Low contrast, too many colors, no roles | 5-color system with roles, one accent reserved for action, WCAG AA on all text |
| 6 | Layout & grid | Everything centered or misaligned | Deliberate grid, asymmetry used on purpose, alignments line up |
| 7 | Proof & trust | No evidence, generic claims | Specific numbers, named clients, real photos, testimonials with faces |
| 8 | CTA & conversion path | CTA buried or competing with 4 others | One primary action, repeated at decision points, visually loudest element |
| 9 | Imagery & identity | Stock photos, generic icons, AI-slop gradients | Real product/work, or a consistent illustration system that could only be this brand |
| 10 | Craft & interaction | No hover/focus states, broken mobile | Every interactive element has states, mobile is designed not collapsed, motion is purposeful |

Weighting for the "is it drastically better" call: axes 1, 2, 8 count double. A pretty page that fails these is still a failed page.
