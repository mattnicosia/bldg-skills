# LinkedIn Post Writer

Create full LinkedIn posts using structures extracted from 880 top-performing posts.

## Quick Start

When asked to write a post:
1. Identify the best post type for the topic
2. Load the template from `references/post-templates.md`
3. Fill in with user's specifics
4. Apply brand voice if available
5. Include CTA stack at end

## Post Types

| Type | When to Use | Key Element |
|------|-------------|-------------|
| **Transformation Story** | Personal journey, credibility building | Timeline contrast (Before → After) |
| **Contrarian** | Challenging wisdom, positioning as expert | "Stop [X]. Do this instead." |
| **Tool List** | Sharing your stack, demonstrating expertise | "[#] tools I (actually) use" |
| **Case Study** | Proving your method works, lead generation | Specific result + breakdown |
| **Resource Curation** | Providing value, building goodwill | "Forget [expensive]. Here's free." |
| **Giveaway** | List building, engagement farming | "Comment [WORD] for free [X]" |

## Universal Post Structure

```
HOOK (1-2 lines)
↓
SETUP (2-4 lines)
↓
BODY (list, story, or proof)
↓
INSIGHT (2-3 lines)
↓
CTA STACK
```

## Formatting Rules (Data-Backed)

From top 10% performers:

| Element | Rule | Data |
|---------|------|------|
| **Length** | 1,400-1,800 characters | +23% engagement vs short posts |
| **Arrows** | Use → ↳ 👉 liberally | 62.5% of top posts use them |
| **CTAs** | Always include at end | 85% of top posts have CTAs |
| **Post type** | Default to image posts | 70% of top 10% were images |
| **Numbers** | Always specific | "$47,329" not "good income" |
| **Parentheticals** | Add for personality | "(actually)", "(religiously)" |

## CTA Stack (Pick 1-3)

| Type | Formula |
|------|---------|
| **Comment trigger** | Comment "[WORD]" and I'll send you [resource] |
| **Repost** | ♻️ Repost to help your network [benefit] |
| **Follow** | Follow me [Name] for [frequency] [content type] |
| **Newsletter** | Subscribe to my newsletter: [link] |
| **Save** | Save this. [Specific action] tomorrow. |

## Voice Integration

If user has a brand voice profile:
1. Load their voice characteristics
2. Use their specific stories, numbers, and journey
3. Match their directness and vocabulary
4. Reference their products/offers appropriately

## Quality Checklist

Before outputting any post, verify:
- [ ] Hook is 1-2 lines with specific number or bold claim
- [ ] Body uses arrows (→) to guide the eye
- [ ] Includes at least one specific number
- [ ] Ends with CTA stack (1-3 CTAs)
- [ ] Total length is 1,400-1,800 characters
- [ ] No vague language ("many", "significant", "lots")
