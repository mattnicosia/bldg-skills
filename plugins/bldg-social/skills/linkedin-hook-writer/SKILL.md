# LinkedIn Hook Writer

Generate scroll-stopping opening lines using patterns extracted from 880 top-performing LinkedIn posts.

## Quick Start

When asked to write hooks:
1. Identify which hook formula(s) fit the topic
2. Reference `references/hook-swipe-file.md` for detailed templates
3. Generate 3-5 options using different formulas
4. Apply the user's brand voice if available

## Hook Formulas

| Formula | Pattern | Best For |
|---------|---------|----------|
| **Number + Bold Claim** | "[Specific #] [surprising result]" | Results, achievements, proof |
| **Contrarian Stop** | "Stop [common behavior]." | Challenging wisdom, expertise |
| **Forget X, Here's Y** | "Forget [expensive]. [Free alternative]" | Resource curation, value |
| **Transformation** | "[Past]: [pain]. [Now]: [result]" | Personal stories, credibility |
| **Emotional Truth Bomb** | "[Strong feeling]. [Explain]" | Hot takes, opinions, debate |
| **Tool List** | "[#] tools I (actually) use" | Tool recommendations |
| **Giveaway** | "[Value]. FREE. Comment [WORD]" | Lead generation |

## Key Principles

- **Specific numbers always**: "$47,329" not "good income", "17 days" not "quickly"
- **Parenthetical personality**: "(actually)", "(religiously)", "(free)"
- **1-2 lines maximum**: Hook must fit above the "see more" fold
- **Lead with surprise**: Most unexpected or specific element first
- **No questions**: Data shows questions underperform vs statements

## Output Format

When generating hooks, provide:
1. 3-5 options using different formulas
2. Label each with the formula used
3. Rank by which fits the topic best
