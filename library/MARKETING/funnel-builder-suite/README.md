# Funnel Builder Suite

A complete suite of 13 coordinated skills that research, plan, write, and
build entire marketing funnels — from the lead magnet to the final follow-up
email — in a single session.

---

## What It Does

Give it your offer and a direction. It handles the rest: asks only what it
needs, recommends the right funnel type, maps every asset, builds them all in
the correct order, saves them to a project folder, and delivers a client-ready
PDF brief when it's done.

It produces **complete, ready-to-deploy copy and HTML** — not outlines, not
templates, not placeholders where the real content should be. Every email,
page, and social post is written in full.

## How to Use It

### Starting a new project

**Always start a new Cowork session for each funnel.** This keeps projects
isolated and prevents the skill from mixing up details between different offers.

1. Open a fresh Cowork session
2. Type something like:
   - *"Build me a lead magnet funnel for my [offer]"*
   - *"I need a full webinar funnel"*
   - *"Create a complete funnel from scratch"*
3. The `funnel-builder` skill will activate and walk you through intake
4. Answer its questions — the more specific you are, the better the output
5. Say **"build it"** when the asset map looks right
6. It builds everything and saves each piece to a project folder as it goes

### Tips for best results

- **Tell it your platform upfront** (Kajabi, ClickFunnels, Webflow, etc.) so
  the HTML and notes are tailored to it
- **Share existing assets** if you have them — paste in your sales page, ebook
  outline, or webinar script so the skill references real content instead of
  writing generic copy
- **Give it a launch date** if you have one — it will schedule the email
  sequence automatically
- **Start fresh each project** — open a new session and tell it to start clean.
  Each funnel should be its own conversation.

### Using individual skills standalone

Every specialist skill also works on its own. If you just need an email
sequence, trigger `email-sequence-generator` directly. If you need a quiz
built without a full funnel, use `quiz-flow-generator`. Each skill is
self-contained and documented.

## Output

Each funnel build produces:

- **A project folder** named after your offer, with numbered subfolders for
  every asset in build order
- **Full HTML pages** ready to open in a browser or paste into your page builder
- **Complete email copy** ready to paste into any email platform
- **A downloadable lead magnet** (PDF or HTML) if applicable
- **A client-ready PDF brief** summarising everything that was built

---

## Context Isolation

Each skill session operates in isolation. It does not carry over details from
previous conversations, other projects, or other Cowork windows. If you notice
it referencing something from a different project, tell it to start fresh and
it will reset.
