# Matt's Taste Profile

Default reference set. The primary anchor is the monday.com Agents screen in Night theme, measured in `monday-night.md`; it goes to the judge on every run. The sites below are the wider set. Screenshot each hero at 1440px during step 1 and feed them to the judge alongside before/after.

## The sites

| Site | Camp | What to steal | What NOT to steal |
|------|------|---------------|-------------------|
| lusion.co | Immersive | Scroll as a narrative device, confident dark canvas, type that sits inside the scene | The WebGL itself. Months of 3D work. Faking it looks cheap. |
| lusion.co/about | Immersive | Studio story told through pacing, big statements with air around them | Same |
| white-desert.com | Cinematic | Full-bleed photography does 90% of the work, restrained serif type, luxury through silence | Nothing. This is the most transferable site on the list. |
| carboncustombuilders.com | Cinematic | Real built work as the hero, premium builder positioning without saying "premium" | Direct peer. Beat it, don't copy it. |
| catalinvintila.design | Editorial-motion | Oversized type, deliberate transitions, portfolio pacing | Motion volume. It works for a designer portfolio, not a GC. |
| labs.google | Playful-product | Bold color blocks, each experiment feels like its own world, clear "try this" CTAs | The whimsy. Wrong register for construction buyers. |
| nothing.tech | Dark hardware | Product shot like a sculpture, dot-matrix/industrial type, dark canvas that feels like equipment not software | The consumer-gadget playfulness. Keep the seriousness. |
| igloo.inc | Immersive | Scroll pacing, cold atmospheric depth, one scene per screen | The 3D itself. Same trap as Lusion. |
| monday.com Agents screen, Night theme | Dark product (primary) | One dominant element per viewport, grey chrome with colour only inside cards, a static ambient field behind opaque cards, one big card beside small ones. Measured in `monday-night.md`. | The board view, which fails hierarchy. The cartoon characters, which are their brand. |
| clickup.com | SaaS-conversion | Product screenshot as hero, relentless CTA repetition, social proof density | The visual style. It's the odd one out on this list. |

## The pattern across all nine

1. **One dominant thing per screen.** Never three competing elements.
2. **Real subject matter over decoration.** Actual work, actual product, actual places. Zero stock, zero gradient blobs.
3. **Type is big and confident.** Headlines are allowed to be huge and short.
4. **Restraint in color.** Mostly neutral canvas, one accent, photography carries the color.
5. **Pacing.** Scrolling feels like a sequence, not a stack of sections.

## The tension to resolve per run

Eight of these are brand/atmosphere sites. ClickUp is a conversion machine. Pick per page:
- **Selling a build, a firm, or a vision** (MCC, BLDG Estimating, Carbon-style): Cinematic. White Desert + Carbon.
- **Selling software** (BLDG OS, NOVATerra, Corvo): Dark product, anchored on the monday Agents screen. Its grey chrome and colour-inside-cards rule, Nothing.tech's industrial treatment (software presented like serious equipment), Igloo/Lusion pacing, ClickUp's CTA density. Do NOT default to generic dark SaaS (glowing UI on black).

Never average the two. A blended page reads as neither.
