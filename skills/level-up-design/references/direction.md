# Picking a Direction

Pick one. Name it. Write why it fits THIS buyer. Then write tokens.

Directions are starting points, not templates. Combine at most two.

- **Editorial**: magazine type, big serif display, strong column grid, lots of whitespace. For authority and expertise sells.
- **Industrial / Spec-sheet**: monospace details, hairline rules, dense data, technical labels. For builders, engineers, operators.
- **Brutalist-clean**: oversized type, flat color blocks, hard edges, no shadows. For contrarian positioning.
- **Swiss / Grid**: strict grid, sans-serif, asymmetric layouts, restrained color. For clarity-first B2B.
- **Material-real**: real photography of work, textures, craft details. For physical products and trades.
- **Dark instrument**: dark UI, one bright accent, product screenshots as hero. For software that should feel powerful. The measured reference is `monday-night.md`: `#111` canvas, two text greys, colour only inside cards, a static field behind the hero.

- **Cinematic**: full-bleed real photography, restrained serif, huge negative space, luxury through silence. For premium builders and high-end work. Reference: white-desert.com, carboncustombuilders.com.

For construction and trades buyers: Industrial and Material-real outperform generic SaaS looks. Real jobsite photos beat any illustration.

## Token sheet (write before layout)

```
Type:     display [font], body [font], scale ratio [x], sizes [..]
Color:    ink, paper, muted, accent (action only), support
Spacing:  base [4 or 8], scale [..]
Radius:   [value, or 0]
Motion:   one rule (e.g. "only CTAs and reveals move, 200ms ease-out")
```
