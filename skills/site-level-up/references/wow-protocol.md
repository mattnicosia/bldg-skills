# Wow protocol (sites)

Impact, not decoration. Same bar as the prompts that already worked.

## Pass bar

Fails if a sharp visitor says "nice" and keeps scrolling.
Passes if hierarchy and one signature moment are obvious in two seconds.

## Audit questions

1. What owns the screen in the first second?
2. Even and polite, or real scale contrast?
3. Material presence, or flat rectangles?
4. Is there a signature moment specific to this product?
5. Are states designed (hover, focus, loading, empty, error)?
6. Did motion change hierarchy, or only add movement?

## Landing / sign-in

- Hero must dominate immediately
- Sign-in is a premium moment, not a leftover form
- One job per viewport. Supporting proof stays secondary

## Allowed push language

Do not invent a brand unless asked. Push:

- extreme hierarchy on the one thing that matters
- one or two signature moments, not twelve
- material / depth / presence
- kill the safe middle

## If this is NOVATerra

Stay inside charcoal / slate + indigo + amber. Wow is stronger presence inside that system, not a new look.

## Anti-patterns

- more animation on an even layout
- generic cards, default type, soft gradient chrome
- rewriting IA to chase a look
- restyling working tokens because a new model arrived
